## 第2页：项目背景

**标题**: 为什么需要智慧水质监测？

**内容要点**:
1. **传统水质监测痛点**:
   - 人工采样周期长（数小时~数天）
   - 数据分散，缺乏系统化管理
   - 事后分析，缺乏预测预警能力
   - 多源数据格式不统一

2. **解决方案**:
   - 多源数据自动采集 + 智能清洗
   - XGBoost机器学习预测
   - 实时异常告警 + 可视化看板
   - 全流程系统化管理

## 第4页：数据采集与清洗

**标题**: 模块① — 多源数据采集与智能清洗

**采集功能**:
- **CSV/Excel导入** — 自动映射中文列名到标准字段
- **模拟传感器** — 以配置频率生成pH/DO/氨氮/浊度/COD等数据，支持异常值注入（2%概率）
- **手动录入** — 单条和批量录入，格式实时校验

**清洗功能**:
- 去重 → 缺失值处理（删除/均值/中位数/线性插值）→ 异常值检测（IQR/Z-Score）→ 归一化（MinMax/Z-Score）
- GB 3838-2002 标准水质校验器

**截图**: 数据管理页面（上传+清洗+表格）

## 第5页：ML预测模型

**标题**: 模块② — XGBoost水质预测模型

**特征工程** (37维特征):
- 滞后特征：前7天历史值 (ph_lag_1 ~ ph_lag_7)
- 滚动统计：3天滚动均值/标准差
- 差分特征：日变化率
- 时间特征：hour/day/month/dayofweek
- One-Hot编码：站点标识

**模型训练**:
- 7个独立XGBoost回归模型（pH/DO/NH3N/浊度/水温/COD/总磷）
- 递进式多步预测（支持1~30天）

**预测结果**:

| 指标 | R² | MAE |
|------|-----|-----|
| pH | 0.832 | 0.055 |
| 溶解氧 | 0.704 | 0.170 |
| 浊度 | 0.938 | 0.125 |
| 水温 | 0.916 | 0.530 |
| COD | 0.936 | 0.254 |
| **平均** | **0.825** | — |

## 第6页：告警与后台管理

**标题**: 模块③ — 异常告警与系统管理

**告警引擎**:
- 12条 GB 3838-2002 预置规则（pH<6/DO<2/氨氮>1.0/浊度>10等）
- 三级严重度：critical / warning / info
- 规则可自定义：阈值/操作符/启用/禁用
- CSV历史持久化，支持分页和严重度过滤

**后台管理**:
- JWT Token认证（HS256 + bcrypt密码哈希）
- RBAC角色：admin / editor / viewer
- 用户管理：创建/列表/启用/禁用
- 站点管理：3预置站点 + CRUD操作

## 第11页：挑战与总结

**标题**: 开发挑战与技术决策

**关键技术决策**:
1. **XGBoost vs LSTM**: 最终选择XGBoost — 小样本数据表现更优，训练快，可解释性强
2. **CSV持久化 vs 数据库**: 选择CSV/JSON文件存储 — 减少部署依赖，适合课程项目规模
3. **JWT + RBAC**: 无状态认证方案，适合前后端分离架构

**关键Bug修复**:
- 特征列数不匹配（训练77列 vs 预测75列）
- NaN JSON序列化500错误
- 滚动窗口TypeError（transform + rolling链式调用）
- 测试框架pytest-asyncio STRICT模式兼容

**项目总结**:
- 4周开发，6大模块，43个API端点，7个ML模型
- 183测试全通过，平均R²=0.825
- 前后端分离，可部署、可演示、可扩展
