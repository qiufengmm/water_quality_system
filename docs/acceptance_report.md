# 水质监测与预测系统 — 验收文档

> 项目名称：基于大数据与机器学习的水质监测与预测系统

> 验收日期：2026年6月9日

---

## 1. 项目概述

本项目基于 Python 机器学习集成方案，构建多源水质数据全流程处理、智能水质预测分析、可视化展示与异常告警、基础系统管理四大核心功能。系统采用 FastAPI 后端 + Vue 3 前端 + XGBoost ML 预测的技术架构，前后端分离，RESTful API 通信。

### 1.1 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 后端框架 | FastAPI | 0.115.6 |
| 数据库/Python | Python 3.13 / Pandas 2.2 | — |
| ML框架 | XGBoost | 2.1.3 |
| 前端框架 | Vue 3 + Vite + Element Plus | 3.5 / 8.0 / 2.14 |
| 图表 | ECharts | 6.1 |
| 认证 | JWT (python-jose) + bcrypt | — |
| 测试 | pytest + httpx | 8.4 / 0.28 |
